Policy

Task Planner Privacy Policy

Effective date: August 13, 2026

Local-first tasks, optional private iCloud sync, no account required.

本機優先任務、可選擇私人 iCloud 同步，不需要帳號。

Core

Your planner data is stored on your device first.

你的規劃資料會優先儲存在裝置上。

Network

No advertising or cross-app tracking. Network use is limited to optional private iCloud sync, purchase validation, and user-directed sharing.

不使用廣告或跨 app 追蹤；網路用途限於可選擇的私人 iCloud 同步、購買驗證與使用者主動分享。

01

Overview

Task Planner is a local-first task planning app designed for capturing tasks, ideas, recurring work, and completion history in one place.

Task Planner 是一款本機優先的任務規劃 app，用來把任務、想法、循環工作與完成紀錄收在同一個地方。

02

Data Storage

Task Planner stores your tasks, plan items, recurring items, tags, tag colors, completion history, dashboard summary data, and display settings on your device. Task Planner does not require an account.

Task Planner 會將你的任務、計畫項目、循環項目、標籤、標籤顏色、完成紀錄、儀表板摘要資料與顯示設定儲存在你的裝置上。Task Planner 不需要帳號。

03

Settings and Preferences

Task Planner stores display preferences such as tag size, text size, completed-task preview count, sound, and navigation theme. If you enable iCloud sync, supported planner settings may sync with your planner data. Onboarding progress and the sync-enabled preference remain local to each device.

Task Planner 會儲存標籤大小、文字大小、完成任務預覽數量、音效與導覽主題等偏好。開啟 iCloud 同步後，支援的規劃設定可能會隨資料同步；新手引導進度與同步開關仍只保留在各裝置本機。

04

Backups

Task Planner provides user-initiated JSON backup export and import from Settings. Exported files are created locally and may be shared through the device share sheet to a destination you choose; Task Planner does not automatically upload or sync them. If you delete the app or clear local app storage without a backup, your saved data may be lost.

Task Planner 可在 Settings 手動匯出與匯入 JSON 備份。匯出的檔案會在裝置上建立，也可以透過系統分享表單交給你選擇的目的地；Task Planner 不會自動上傳或同步備份。如果沒有先備份就刪除 app 或清除本機 app 儲存空間，已保存的資料可能會遺失。

05

Optional iCloud Sync

Task Planner Pro users may explicitly enable sync. When enabled, planner data is stored in the user's private CloudKit database under their Apple iCloud account so it can merge across supported devices. Sync is off by default, local data remains available offline, and turning sync off stops future synchronization on that device.

Task Planner Pro 使用者可以主動開啟同步。開啟後，規劃資料會儲存在使用者 Apple iCloud 帳號的私人 CloudKit 資料庫，以便在支援的裝置間合併。同步預設關閉，本機資料仍可離線使用；關閉同步會停止該裝置後續的同步。

06

Purchases and RevenueCat

Task Planner uses RevenueCat to validate the one-time Pro purchase and provide the Pro entitlement. RevenueCat receives purchase history and an automatically generated anonymous App User ID for app functionality and purchase analytics. Task Planner does not provide RevenueCat with a custom user ID, name, email address, or advertising identifier, and does not use this information for tracking. See the RevenueCat Privacy Policy.

Task Planner 使用 RevenueCat 驗證 Pro 一次買斷購買並提供 Pro 權限。RevenueCat 會基於 app 功能與購買分析處理購買紀錄及自動產生的匿名 App User ID。Task Planner 不會提供自訂使用者 ID、姓名、Email 或廣告識別碼，也不會用於追蹤。請參閱 RevenueCat 隱私權政策。

07

Network Use

Task Planner otherwise works with local device storage. When you export a backup, the system share sheet may pass the file to a destination you choose; Task Planner does not automatically upload backup files. The app does not use advertising, cross-app tracking, or push notifications.

除此之外，Task Planner 以裝置本機儲存運作。匯出備份時，系統分享表單可能會將檔案交給你選擇的目的地；Task Planner 不會自動上傳備份檔案。App 不使用廣告、跨 app 追蹤或推播通知。

08

如有支援或隱私相關問題，請聯絡 zis.tech.support@gmail.com。

這份政策可能會隨 Task Planner 的變更而更新。政策更新時，上方的生效日期也會一併更新。
