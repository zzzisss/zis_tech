Privacy

Local-first storage

Task Planner currently does not require an account, tracking, analytics SDKs, push notifications, or cloud sync. Manual JSON backup export and import are available from Settings.

Task Planner 目前不需要帳號，也不使用追蹤、分析 SDK、推播通知或雲端同步。你可以在 Settings 手動匯出與匯入 JSON 備份。
