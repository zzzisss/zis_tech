Data Note

Task Planner provides manual JSON backup export and import from Settings. Exported files are user-controlled and are not automatically uploaded or synced.

Task Planner 可在 Settings 手動匯出與匯入 JSON 備份。匯出的檔案由使用者自行管理，不會自動上傳或同步。

01

Overview

Task Planner is a local-first planning app. Your planner data is stored on your device first. Pro users can explicitly enable private iCloud sync from Settings.

Task Planner 是一款本機優先的規劃 app。規劃資料會優先儲存在裝置上；Pro 使用者可在 Settings 主動開啟私人 iCloud 同步。

04

Data Retention Note

Before reinstalling the app or clearing local app storage, use Settings to export a JSON backup if you want to keep your planner data. Importing a valid backup replaces current local planner data only after in-app confirmation.

重新安裝 app 或清除本機 app 儲存空間前，如果想保留規劃資料，請先在 Settings 匯出 JSON 備份。匯入有效備份時，只有在 app 內確認後才會取代目前的本機規劃資料。

05

Pro Purchase and iCloud

If a Pro purchase is not recognized, use Restore Purchases in Settings with the same Apple account. iCloud sync is optional and must be enabled manually. Both devices need access to the same iCloud account and an active Pro entitlement.

若 Pro 購買未被辨識，請使用相同 Apple 帳號並在 Settings 點選「恢復購買」。iCloud 同步是可選功能，必須手動開啟；兩台裝置需使用相同 iCloud 帳號並取得有效 Pro 權限。
