# zis tech Website Style Guide

Last updated: 2026-06-28

Use this note when updating `C:\workspace-data\zis_tech` public pages.

## Direction

The current public-site direction is `Spark Minimal`:

- black and white
- calm, precise, useful
- restrained borders and small radii
- product-first, not marketing-heavy
- clear app rows and document-like product pages
- English explanation followed by Traditional Chinese reference copy

## Structure

Homepage:

- use the `zis tech` wordmark in the header
- use the Orbit Mark in the hero
- show apps as clear list rows
- show App Store links only for apps already published

App overview pages:

- use the same header navigation: `Overview`, `Privacy`, `Support`
- hero uses app icon or a restrained mono mark
- App Store QR appears only for published apps with a QR asset
- avoid bottom `All apps` links because the header wordmark already returns home

Privacy and support pages:

- keep legal/support claims stable unless app behavior changes
- use document rows with numbered sections
- add Chinese reference copy under explanatory English paragraphs

## Assets

Use final brand assets from `brand-assets`:

- wordmark: `brand-assets/png/zis-tech-wordmark-primary.png`
- orbit mark: `brand-assets/png/zis-tech-orbit-mark-primary.png`
- favicon: `brand-assets/png/zis-tech-favicon.png`

Do not use the old circular zis logo.

## Tone

Prefer short, grounded wording:

- local-first
- no account required
- manual backup when true
- quiet, useful, close to everyday work

Avoid:

- exaggerated marketing claims
- decorative celestial language beyond the parent brand line
- large rounded cards or pill-heavy controls
- duplicate navigation links
