Before reinstalling

Pro Collection backups include saved formulas and notes. Log and settings are not included.

Pro 的 Collection 備份包含公式與備註，不包含 Log 與設定。

01

Reporting an issue

Please include your device model, iOS version, Dice Box version, and the steps that led to the issue. A screenshot helps when the problem is visual.

回報問題時，請附上裝置型號、iOS 與 Dice Box 版本，以及重現步驟；畫面問題可附截圖。

02

Collection backups

Dice Box Pro can export Collection as a JSON file and import it on another installation. Import adds new saved formulas; matching entries remain unchanged. Keep a copy before reinstalling or changing devices.

Dice Box Pro 可匯出 Collection JSON，並在另一個安裝環境匯入。匯入會加入新收藏，已存在的相同項目會保留。重新安裝或換機前，請先保存備份。

03

Restore Purchases

If Dice Box Pro is not recognized, open Settings and choose Restore Purchases while signed in with the Apple account used to buy it.

若 Dice Box Pro 未被辨識，請使用原購買的 Apple 帳號，在 Settings 點選 Restore Purchases。
