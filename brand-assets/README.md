# zis tech brand assets

This folder keeps source, SVG, transparent PNG, canonical aliases, and preview assets for the `zis tech` brand identity.

## Final Direction

The selected core symbol is the original `2 / Orbit Mark` direction: lowercase `z i s`, an upper orbit, a lower orbit, a lower-left dot, and an upper-right star point.

Use this mark as the final parent-brand symbol. Do not use the older circular `zis` logo.

The primary brand wordmark is `zis tech`, using the final orbit-mark brand board and faithful PNG exports as the current visual reference.

## Folder Structure

- `source/` - original reference boards and raster source material.
- `svg/` - clean editable vector redraws for websites, documentation, and design handoff.
- `png/` - transparent PNG exports and practical canonical aliases.
- `preview/` - non-transparent previews on warm background for quick visual checking.

## Use First

For near-term website, README, social, splash, and app-store mockups, prefer the faithful PNG files because they are closest to the selected final boards.

- `png/zis-tech-orbit-mark-faithful-transparent.png`

## Practical Guidance

- Website header: use `png/zis-tech-wordmark-primary.png` or `png/zis-tech-lockup-horizontal.png`.
- Favicon: use `png/zis-tech-favicon.png`.
- Social avatar: use `png/zis-tech-avatar.png`.
- App splash or compact stamp: use `png/zis-tech-orbit-mark-primary.png`.
- README or visual signature: use `png/zis-tech-lockup-horizontal.png` with the English brand line.
- Dark background: use the matching `reverse` file.

For websites, README banners, App Store images, and social graphics, confirm the intended use and dimensions before creating a final composed graphic.

## Brand Line

English: `A small celestial core for ideas, tools, and everyday life.`

Traditional Chinese: `一個小小的星體核心，承載你的生活所需、所見所聞的日常工具。`

## Tone

Calm, precise, thoughtful, lightly celestial, close to everyday life.

Keep the mark quiet. Do not add extra stars, extra orbits, glow effects, cartoon planet treatments, or loud gradients.
