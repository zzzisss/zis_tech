Prompt Buffet Privacy Policy

Effective date: May 31, 2026

Local-first prompts, manual backup, no account required.

本機優先 prompt、手動備份，不需要帳號。

Core

Your prompts and app data are stored on your device.

你的 prompt 與 app 資料會儲存在你的裝置上。

Network

No advertising, third-party tracking, analytics SDKs, or account-based cloud sync currently used.

目前不使用廣告、第三方追蹤、分析 SDK，或以帳號為基礎的雲端同步。

01

Overview

Prompt Buffet is a local-first prompt app designed for collecting, organizing, searching, and quickly reusing everyday prompts for daily work and writing.

Prompt Buffet 是一款本機優先的 prompt app，設計給日常工作與寫作中收集、整理、搜尋並快速重複使用 prompt。

02

Data Storage

Prompt Buffet stores your prompts, categories, settings, trash, and local usage stats on your device. Prompt Buffet does not require an account.

Prompt Buffet 會將你的 prompt、分類、設定、垃圾桶與本機使用統計儲存在你的裝置上。Prompt Buffet 不需要帳號。

03

Backups

Prompt Buffet supports manual JSON backup export and import. Backup files are created only when you choose to export them. You are responsible for where exported backup files are saved or shared.

Prompt Buffet 支援手動匯出與匯入 JSON 備份。只有在你選擇匯出時，才會建立備份檔。匯出的備份檔要儲存或分享在哪裡，由你自行決定與負責。

Importing a backup replaces the current local app data only after you confirm the import.

匯入備份時，只有在你確認匯入之後，才會取代目前的本機 app 資料。

04

Data Collection

Prompt Buffet does not currently collect personal data. Prompt Buffet does not currently use advertising, third-party tracking, analytics SDKs, or account-based cloud sync.

Prompt Buffet 目前不蒐集個人資料，也不使用廣告、第三方追蹤、分析 SDK 或以帳號為基礎的雲端同步。

05

Network Use

Prompt Buffet is currently designed to work with local device storage. If future versions add sync, cloud backup, analytics, or other network features, this privacy policy will be updated before those features are released.

Prompt Buffet 目前設計為使用裝置本機儲存。如果未來版本加入同步、雲端備份、分析或其他網路功能，這份隱私權政策會在那些功能發布前更新。

06

Contact

For support or privacy questions, contact zis.tech.support@gmail.com.

如有支援或隱私相關問題，請聯絡 zis.tech.support@gmail.com。

07

Changes

This policy may be updated as Prompt Buffet changes. The effective date above will be updated when the policy changes.

這份政策可能會隨 Prompt Buffet 的變更而更新。政策更新時，上方的生效日期也會一併更新。
