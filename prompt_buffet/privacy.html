Prompt Buffet Privacy Policy

Effective date: 2026-05-31

Prompt Buffet 是一個 local-first 的 prompt 收納 app，主要用來整理、分類、搜尋與複製常用 prompt。

Data Storage

Prompt Buffet 會將 prompt、分類、設定、垃圾桶資料，以及本地使用統計儲存在你的裝置上。

Prompt Buffet 目前不需要帳號。

Backups

Prompt Buffet 支援手動 JSON 備份匯出與匯入。備份檔只會在你主動匯出時建立，並由你自行決定儲存或分享位置。

匯入備份只會在你確認後覆蓋目前本地資料。

Data Collection

Prompt Buffet 目前不蒐集個人資料。

Prompt Buffet 目前沒有帳號系統、廣告、第三方追蹤、分析 SDK，或雲端同步功能。

Network Use

Prompt Buffet 目前以本地資料為主。如果未來加入同步、雲端備份、分析或其他網路功能，這份隱私政策會在該功能正式推出前更新。

Contact

如果有支援或隱私相關問題，請聯絡 zis.tech.support@gmail.com。

Changes

這份政策可能會隨 Prompt Buffet 的功能變更而更新，更新時會同步調整上方生效日期。
