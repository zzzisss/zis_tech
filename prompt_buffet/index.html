Local-first prompt shelf

Prompt Buffet

在 iPhone 收藏常用 AI 提示詞、回覆模板與寫作草稿。分類收好，需要時一鍵複製。

For

Everyday prompts, reusable instructions, writing starters, and small text patterns you want close at hand.

適合日常 prompt、可重複使用的指令、寫作開頭，以及想放在手邊的小型文字模板。

Principle

Local-first, searchable, and no app account required. Keep your prompt library on your iPhone and export or import JSON backups when you need them.

以本機儲存、可搜尋、不需要 app 帳號為核心。提示詞留在 iPhone，並可手動匯出或匯入 JSON 備份。

01

Prompt library · 提示詞收藏

Collect the prompts you use often so they are ready before the next conversation, draft, or task.

收下那些經常使用的 prompt，讓下一次對話、草稿或任務開始前就能快速取用。

02

Categories · 兩層分類

Keep prompts grouped by purpose without turning the library into a heavy system.

依照用途分類 prompt，但不讓資料庫變成笨重的管理系統。

03

Fast reuse · 一鍵複製

Find, open, and copy the text you need with a short path back to your work.

快速找到、打開並複製需要的文字，讓你很快回到原本的工作。

04

Manual backup · 手動備份

Export and import JSON backups manually so your prompt library remains portable.

手動匯出與匯入 JSON 備份，讓你的 prompt 資料庫仍然可以被帶走。

05

Search and pin · 搜尋與釘選

Search your library or the current category, and pin the snippets you want to find quickly. Core local organizing tools are free.

搜尋全部內容或指定分類，並釘選常用文字。收藏、分類、搜尋與手動備份等本機核心功能可免費使用。
